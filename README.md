# Largest of Two Numbers 🔢

## Description

Largest of Two Numbers is a simple C program that accepts two numbers from the user and determines which number is larger.

The program uses `if-else` statements to compare the two numbers.

## Features

* Simple and beginner-friendly
* Accepts two numbers as input
* Compares two numbers
* Handles equal numbers
* Uses basic C conditional statements

## Technologies Used

* C Programming
* Standard Input/Output Library (`stdio.h`)

## How It Works

The program:

1. Reads two integer values from the user.
2. Compares the first number with the second number.
3. Displays the larger number.
4. Displays a message if both numbers are equal.
